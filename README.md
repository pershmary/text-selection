# Демо выделения текста в Sabydoc

Запуск из корня проекта: `python3 -m http.server 3000 --bind 0.0.0.0`.
Зависимости и сборка не нужны.

Оболочка окна взята напрямую из `demo.html` репозитория https://github.com/pershmary/table-widget
(коммит 618ecbe6562f227f0668d25849c17595dccca9fa).
Шапка, панели и верхний тулбар сохранены из оригинала. Исходные стили, иконочные шрифты,
Inter и скрипт тени находятся в `vendor/table-widget` без изменений.
Вместо таблицы размещён редактируемый документ для будущего демо выделения.
Табличная логика и команды тулбара не подключены. Ввод и выделение текста — нативные.

Цвета и типографика подключены из https://github.com/MarieSmi/ui-kit
(коммит `c7440fec3845780f94b29911849592481f29a19f`). Локальные токены и шрифты
находятся в `vendor/ui-kit`, соответствие стилям окна — в `styles.css`.
Геометрия и расширенные иконочные шрифты окна сохранены из table-widget.

Стили документа соответствуют «Стили документа SabyDoc.pdf»: заголовок документа
36/44, заголовки h1–h5 — 32/42, 28/32, 24/30, 20/26, 18/26; текст — 16/24.
Размеры используют токены ui-kit. Вес заголовков и жирного текста — 700 по PDF
(токен Bold кита равен 600, поэтому используется локальная переменная).
У текстовых блоков нет padding, вертикальные отступы заданы через margin.
Отступы заголовка документа 48/32 из схемы перенесены в margin; у остальных
блоков взяты только значения margin из схем, padding не добавлен.
