# Демо выделения текста в Sabydoc

Запуск из корня проекта: `python3 -m http.server 3000 --bind 0.0.0.0`.
Зависимости и сборка не нужны.

Оболочка окна взята напрямую из `demo.html` репозитория https://github.com/pershmary/table-widget
(коммит 618ecbe6562f227f0668d25849c17595dccca9fa).
Шапка, панели и верхний тулбар сохранены из оригинала. Исходные стили, иконочные шрифты,
Inter и скрипт тени находятся в `vendor/table-widget` без изменений.
Вместо таблицы размещён редактируемый документ для будущего демо выделения.
Табличная логика и команды тулбара не подключены. Ввод и выделение текста — нативные.

Цвета и типографика подключены из https://github.com/MarieSmi/ui-kit
(коммит `c7440fec3845780f94b29911849592481f29a19f`). Локальные токены и шрифты
находятся в `vendor/ui-kit`, соответствие стилям окна — в `styles.css`.
Геометрия и расширенные иконочные шрифты окна сохранены из table-widget.

Стили документа соответствуют «Стили документа SabyDoc.pdf»: заголовок документа
36/44, заголовки h1–h5 — 32/42, 28/32, 24/30, 20/26, 18/26; текст — 16/24.
Размеры используют токены ui-kit. Заголовки — Semibold (600), через токен
`--font-font-weight-bold`; жирный текст — 700.
У заголовка документа padding 48px сверху и 32px снизу, margin 0.
У остальных заголовков и абзацев padding 0, отступы заданы через margin.

## Плавающий тулбар документа

При частичном или полном выделении одного текстового виджета вне таблицы появляется
тулбар «Форматирование». При выделении нескольких виджетов, включая частично
выделенные крайние блоки, — «Форматирование + объединение» с кнопками объединения
и удаления по макету Figma `2243:184539`. В обоих режимах обработчики кликов
есть только у кнопок начертания: жирный, курсив, подчёркивание и зачёркивание.
Остальные кнопки, включая «Объединить» с иконкой cbuc-icons24 U+EBD1, представлены
без действий. Выделение сохраняется при форматировании. Логика находится
в `document-toolbar.js` и не использует команды таблицы.
Подпись «Смешанный» зависит от типов выбранных виджетов; несколько абзацев
одного типа сохраняют подпись «Основной текст». В режиме «Форматирование»
сохранена кнопка SabyAI без обработчика клика.
Отдельные пункты списка выделяются как самостоятельные виджеты, без номера
в подложке. При выборе всего списка сохраняется общая подсветка списка.

В блоке изображения размещена сгенерированная иллюстрация userflow
в светло-фиолетовых тонах (`assets/userflow.png`). Она адаптируется к ширине
документа с сохранением пропорций и выделяется как единый виджет.

## Таблица

Интерактивная таблица, её CSS и скрипты взяты из `pershmary/table-widget`,
коммит `57ff125501e23732d436a180ba5aa0b4a24be97e`.
Разметка заполнена примерами выделения; подключены ячейки, диапазоны, маркеры,
тулбары, настройки и расширенный режим. Ячейки редактируются отдельно от документа.
В `table.js` добавлена одна интеграционная проверка: сочетания отмены/повтора
перехватываются только в таблице и её окнах, чтобы сохранить обычную отмену в абзацах.
Если выделение мышью начинается в другом виджете документа и доходит до таблицы,
таблица включается целиком, в том числе при движении снизу вверх. Выделение,
начатое внутри таблицы, сохраняет правила выбора текста и диапазонов ячеек.
Подсветка таблицы ограничена её рамкой, без внешних отступов. Во время выделения
из документа и пока таблица входит в него ховер, маркеры и линия изменения ширины скрыты.
